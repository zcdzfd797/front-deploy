# 前端部署工具

一个本地运行的前端发布辅助工具，支持从 Git 项目读取信息、执行构建打包，并通过 SSH 上传到目标服务器完成部署。

## 当前能力

1. 添加项目
- 选择本地工作副本目录
- 自动解析 Git 信息（项目名、分支、最新提交）
- 保存项目记录与备注

2. 编辑配置
- 维护构建命令
- 配置部署服务器（地址、端口、账号、密码/私钥）
- 支持导入 JSON 连接配置
- 支持测试 SSH 连通性

3. 打包与部署
- 执行构建命令并实时输出日志
- 自动打包为 zip
- 上传到服务器指定目录
- 备份同名目录（时间戳）并解压新包
- 记录最近部署时间和部署状态

## 运行方式

```bash
npm install
npm run dev
```

默认启动地址：`http://localhost:3000`

## 目录结构

```text

│  ├─ style.css

├─ server.js
```
